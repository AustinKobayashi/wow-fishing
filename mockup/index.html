How these numbers are calculated

The helper samples N(μ, σ²), rejecting every value below the minimum. μ = (min + max × modifier) / 2 and σ = (max - min) / (2 × Φ⁻¹(1 - tail / 2)). Max sets the spread, not an upper bound. The tail input is not the missed-event probability.

Cutoff skip probability is Q((cutoff - μ) / σ) / Q((min - μ) / σ), or 100% when cutoff ≤ min. Expected skips per 1,000 refer to detected events that enter the timing branch, not all casts or failed catches.

The current main loop sleeps for R, then checks elapsed + R < WOW_FISHING_TIME. With detection age A and negligible overhead, it requires A + 2R < window, so the combined threshold is min(cutoff, (window - A) / 2). Actual scheduling overhead can increase skips.

Cast delay is conditional on the previous reel sample, which becomes its mean. This preview is a single conditional distribution, not the overall cast distribution. Plotted tails extend beyond the viewport. Probability calculations include the full tail.
